Core Mechanics

Melee Combat: Melee attacks can use Conduit Attributes with favored physical Core pairs: Flame + STR (Thermal), Frost + FIN (Cryogenic), or Lightning + AGI (Galvanic). Favored pair grants damage bonus equal to lower attribute in pair.

Effect Synergies:

  • Flame: grants 3 SP instead of 2.
  • Frost: and become Sustained Effects for the round.
  • Lightning: grants +1 SP; activates on 7+ dice.

Charge Engine: Amp abilities build +1 Charge of matching element (swapping elements resets charges to 0). Bursts require and consume 3 Charges.

Minor Touch: Warm/spark (Flame), cool/freeze (Frost), static shock/clear (Lightning) without rolling.

Class Modifications (25,000 Cr · Max 2)

Act Mod Effect
Duality Hold charges of 2 elements simultaneously (shared max 3). Burst consumes all. Amping overrides when full.
Infinity Can activate Amp abilities even when holding max 3 Charges, gaining active effects without gaining charges.
Intensity Sacrifice a (8+) on tests using Conduit Attributes to generate 1 matching (up to max capacity).
Finality Can activate Burst with <3 Charges, but cannot gain Charges of any element until the end of the round.
Ingenuity When Amping a different element, convert all existing Charges into the new element instead of losing them.
