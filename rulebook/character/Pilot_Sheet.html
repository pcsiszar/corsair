Operation Modes

Attached
Attribute SwapSubstitute STR, AGI, or FIN with Exodrone's Power, Speed, or Precision. Always uses Exodrone Attributes for skill tests.
Detached
Remote CommandExodrone acts independently using its own Attributes. It can use the Pilot's AP pool or gain AP through Exo-Skills.

Class Mods — 25,000 Cr each

Extra Battery
Max Battery limit increases to 12.
Remote Charging
Lose 1 Battery per 4 pts damage (not 3). Can gain Batteries in Detached Mode.
Biomechanical Dynamo
While Attached, sacrifice Hits on own Physical tests to gain 1 Battery per Hit.
Turbo Boost
After using an Exo-Skill, one chosen Exodrone Attribute gains +1 Upgrade until end of Player Turn.
Charger Mode
If no Battery-costing skill was used and no Exodrone Attribute was tested, regain 2 extra Batteries end of Round.
