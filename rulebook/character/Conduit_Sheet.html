Basic Mechanics

Minor Touch Effects (No roll):

  • Flame: Warm objects, melt frost, dry garments.
  • Frost: Cool beverages, freeze water, soothe burns.
  • Lightning: Static shocks, light low-voltage lights.

Melee Combat: Melee attacks can use Conduit Attributes matching Strength (Flame), Finesse (Frost), or Agility (Lightning). Reach 3, Dmg Bonus = half Conduit Attribute used (rounded up).

Effect Synergies:

  • Flame: Crit effects grant 3 SP instead of 2.
  • Frost: Blockers act as Permanent Blockers for round.
  • Lightning: Chains +1 SP; triggers on 7+ dice.

Charges: Amp skills build element Charges. Bursts require 3 Charges, venting them completely. Changing elements resets charges to 0.

Class Modifications

Duality You can hold charges of two elements simultaneously. Max Charges limit is still shared.
Infinity You can continue activating Amp Skills even when at maximum Charges for an element.
Intensity Generate charges by sacrificing Hits on any test using your Conduit Attributes.
Finality Use Burst Skills without 3 Charges, but you cannot gain charges until the end of the round.
Ingenuity Convert your current Charges into the new element when using a different Amp Skill.
