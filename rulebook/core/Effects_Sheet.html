Quick Reference: Effects

Tactical Maneuvers & Narrative Influence

Effects represent tactical advantages, narrative twists, or scene alterations. To activate an effect, you must sacrifice Hits scored during either a Success Roll or an Action Roll. Your narration must support the effect's manifestation.

Combat & Performance Effects

Effect Name Activation & Mechanics
Instant Benefits
Crit Effect
Success Roll · Generic
 For every Hit spent, increase the total Success Points scored on the roll by 2.
Chain Effect
Action Roll · Multi-Target
 Spend 1 Hit per additional eligible target. Roll the test normally; the highest result applies to all targets. Must spend resources (ammo, charge) for each target. Cannot chain already multi-target actions.
Push Effect
Success Roll · Movement
 Spend 1 Hit to move a creature horizontally up to 4 meters. You may move alongside at no cost. (Willing: Success Test; Unwilling: Complex Test).
Persistent & Tactical Influences
Upgrade / Downgrade
Action Roll · Situational
 Spend Hits to create situational advantages/disadvantages. Target receives ±1 Upgrade/Downgrade per level of the effect. Lasts until the creating condition is no longer relevant (e.g., standing up from prone).
Blocker Effect
Action Roll · Hindrance
 Set aside Hits to stop future actions. Each Hit negates the highest die scored on a blocked action's test. If no test is normally required, the target must pass a Simple Test.
Persistent Blocker
Action Roll · Continuous
 Similar to Blocker, but set-aside Hits reset after each blocked action. Ends if a test succeeds despite the block or conditions change. (e.g., Disguises, Restraints).
Timing & Reactions
Trigger Effect
1 AP · Delayed Action
 Specify a trigger event and an action. When the trigger occurs, immediately roll the test. Requires Concentration; taking other tests or being attacked breaks the effect. 1 AP is spent on the turn of declaration.
Persistent Trigger
Delayed Action · No Conc.
 A Trigger Effect that does not require concentration. Typically reserved for items like traps or automated security systems.

General Effect Rules

Narrative Consistency: The GM's deciding factor for an effect is: "Is this effect possible using this Attribute Pair and this narration?"

Concentration: While waiting for a Trigger, you are concentrating. If you take any other test or someone succeeds at an action to break your concentration (like an attack), the effect is lost.

Removing Effects: A creature in a position to remove an ongoing effect can roll a Simple Test to remove one Hit that was set aside for that effect.
